你好，我是 **Ethan Lee**，法律姓名是 **Yifeng Li / 李易峰**。

目前我是 **香港理工大学（PolyU）计算机科学三年级**学生。过去几年里，我做过从数据与评测，到 AI 应用，再到 agent systems 的不少项目；相比“把一个功能做出来”，我现在更在意的是：**这个产品是否自然、顺滑、值得被长期使用**。

## 我主要在做什么

最近我最关注三件事：

1. **AI Companion**：让人与模型的交互更自然，而不是只停留在一次次 prompt。
2. **Agent-native workflows**：把任务拆给 agent，并让它们在真实工作流里稳定协作。
3. **产品化落地**：从 demo 往前走，做到真正可持续、可维护、可复用。

我参与或做过的一些方向包括：

- **Open LLM Vtuber**：一个支持语音交互、视觉感知和 Live2D 形象的 AI Companion。
- **CLIClaw**：一个面向长期运行 agent 的多 Agent 编排平台。
- **DeepLecture / Navox / MolBot**：分别围绕 AI-native 学习、移动端 agent 执行和多 Agent 金融分析展开。

## 这个博客会写什么

这里不会只放“教程”或者“周报”。我更想把它作为一个长期工作台，记录：

- 我在做产品和项目时的判断过程
- agent systems 里真正踩过的坑
- 一些关于交互、工作流和产品感觉的思考
- 在学校、研究和实习准备中的阶段性总结

## 为什么要搭这个站

我一直觉得，很多有价值的思考都散落在聊天、issue、commit、临时文档里。

搭这个博客，是想把这些零散内容慢慢沉淀成一套更清晰的记录：哪些事情值得长期做、哪些系统为什么这么设计、以及我到底想构建怎样的 AI-native 产品。

如果这些内容对你有启发，欢迎通过邮件联系我。
